INSTRUCTIONS for using the website

These instructions are intended to make it easier to use the Tandara Family Digital Archive and to navigate genealogy pages, family branches and interactive diagrams.

The guide explains how to find a specific person by genealogy code or by entering the person’s name together with the father’s and mother’s names. It also describes the procedure for requesting access to the protected family archive.
