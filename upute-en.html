INSTRUCTIONS for using the website

Quick start

To explore family relationships, open Genealogy, then the relevant family branch or diagram. The combined diagram shows the four main branches. Filip’s Livno branch has a separate diagram; a connection to the root of the combined diagram should not be assumed.

  1. If you know the genealogy code, enter it in the Code field and select Find.
  2. If you do not know the code, start with the Person name field. Narrow the search using the Father's name and Mother's name fields when you know those details.
  3. Before choosing a person, compare the full code, parents and family branch. Matching names alone do not establish that two records refer to the same person.
  4. Use ＋ and − to zoom, and Fit to adjust the diagram view.

Reading and comparing records

The family text and diagram may contain complementary information. Compare them using the full genealogy code and family context. A missing date or name does not by itself mean that a person or relationship did not exist. When two records differ, note both versions and their sources rather than guessing which is correct.

Use the Croatian or English language link to change language. Genealogy codes also help match records across the two language versions.

Sending corrections and additions

On the Contacts page, provide the page title or link, the person’s full code if known, the current information and the proposed correction. Include a source supporting the addition, and make clear whether the information comes from a document or family memory.

Do not enter information about living people or private family documents in the public guestbook. To request access to the protected archive, follow the instructions and the protected form link on the Contacts page.
